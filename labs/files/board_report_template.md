# قالب تقرير اللجنة التنفيذية (صفحة واحدة)

1. **الرسالة في سطرين:** هل البرنامج يحمي ويُسرّع، أم يعدّ فقط؟
2. **ثلاثة مقاييس فاعلية** مع الاتجاه خلال السنة.
3. **علامة واحدة للإشراف الشكلي** وما يجري بشأنها.
4. **الحوادث:** كيف اكتُشفت، وكم استغرق احتواؤها.
5. **القدرة:** الطلب المتوقع، والقوى العاملة اللازمة، والفجوة.
6. **ثلاثة قرارات** تطلبها من اللجنة التنفيذية، لكل منها مالك وموعد.
