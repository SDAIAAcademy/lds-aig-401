# تصميم برنامج حوكمة الذكاء الاصطناعي وتشغيله: المختبرات

خمسة مختبرات لمقرر أكاديمية سدايا **LDS-AIG-401**، مدة كل منها 96 دقيقة. المختبرات صفحات إرشادية بالعربية: الهدف،
والملفات، وخطوات بدقائقها، وجداول تُملأ، وأسئلة تحقق، وتمرين إضافي ✱، وملاحظات للمدرب. يعمل المشارك في جدول بيانات
ومحرر نصوص. لا كود يكتبه المشارك.

كل المختبرات في جهة واحدة: **وزارة المهارات والتعلم المستمر**، وزارة افتراضية في المملكة. الوزارة ووحداتها وأنظمتها
ووثائقها وبياناتها مخترعة للتدريب، والأشخاص بأدوارهم فقط، ولا رقم هاتف ولا رقم هوية ولا رقم حساب في أي ملف. المرجعيات
الوطنية التي تذكرها الملفات حقيقية، وتُذكر حالة كل منها. تعمل المختبرات 1.1 و2.1 و3.1 على شريحة من وحدتين: المنح التدريبية
(U1) والاختبارات المهنية والاعتماد (U2).

## ما يحتاجه المشارك

- حاسوب عليه جدول بيانات يفتح ملفات CSV بترميز UTF-8، ومحرر يقرأ Markdown.
- لا حساب، ولا مفتاح، ولا نموذج يُنزَّل ولا يُستدعى.
- مستوى الذكاء الاصطناعي في كل مختبر:

| المختبر | المستوى |
|---|---|
| 1.1 و1.2 و2.1 و3.2 | مدرّس فقط، مهيأ لطرح الاعتراضات، ونموذج مجاني مستضاف يكفي |
| 3.1 | دون ذكاء اصطناعي: تدريب على محاكاة اللجنة |

حزمة الحالة اصطناعية ويصنفها المقرر «عام» للتدريب. لا يُدخل في أداة ذكاء اصطناعي توليدي ما يصنف «مقيد» فأعلى من جهتك.

## للمدرب

- `uv run labs/solutions/check.py` يعيد حساب كل رقم في الحلول المرجعية وفي أمثلة الشرائح، ويطبع PASS أو أول فرق.
  `uv run labs/solutions/check.py 2.1` لمختبر واحد، و`ex` لأمثلة الشرائح. لا يحتاج إلا مكتبة Python القياسية.
- `uv run labs/_tools/prepare_files.py` يعيد توليد كل ملفات `files/` بالبايتات نفسها (بذرة ثابتة).
- `solutions/answer_key.md`: كل مشكلة مزروعة، وأين هي، وأي مختبر يجدها.
- ما شُغّل: المولّد والتحقق كاملين على هذه الملفات، وكل الأرقام في الحلول والشرائح منهما. لا مختبر يستدعي نموذجًا،
  فلم يُشغّل أي نموذج، والمطالبات الموجهة إلى المدرّس لا تُقيَّم.
- لا تدخل هذا المستودع: حالة التحليل غير المعروضة، وملفات اجتماع اللجنة تحت الملاحظة، والأحداث الجديدة للمناقشة.
